# Research trends

Persist 1–30 evidence-backed directions without generating media. Each direction needs a name, description and 1–30 citations with source, public HTTP(S) URL, sourceType, observedAt and observation. The agent performs public research; the backend does not scrape URLs. External observations and internal performance evidence remain separate. Do not invent numeric trend scores. Read stored candidates through `/api/v1/skills/research/{researchRunId}`. Pass a candidate ID into collection creation to preserve lineage.

Read [`skills/research-trends/SKILL.md`](../../skills/research-trends/SKILL.md), its input reference and five examples. Use the shared plan/start/monitor/resume protocol in the [overview](../codex-skills.md).
