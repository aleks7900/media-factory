# Statistical methods and limitations

Exact population count, arithmetic mean, median, p25, p75 and p90 are computed in PostgreSQL. Percentiles use continuous linear interpolation, equivalent to position `(n-1)*p` between sorted observations. Monetary aggregation remains decimal SQL; descriptive interval computation uses double precision and is not an accounting ledger.

For a categorical value, the treatment group has that explicit value and the comparison has another known value. Absolute effect is treatment minus comparison mean. Relative effect divides by the absolute comparison mean; a zero baseline returns unavailable. Boolean false is observed evidence, distinct from a missing property. Skewed metrics retain medians/quantiles beside means; no outlier is silently removed.

Uncertainty uses a deterministic percentile bootstrap of the mean difference: 1,000 independent resamples per group, persisted seed, 2.5th and 97.5th percentiles. At most 2,048 assets per group are selected by deterministic asset-hash ordering. Exact population summaries still use all assets. When capped, intervals describe a sampled approximation and a visible warning records the cap; they are not claimed to be exact full-population inference. Cost per approved asset uses paired `(cost, approval)` resampling and a ratio of sums, retaining rejected spend. At least 950 valid bootstrap replicates are required; zero approvals cannot yield a numerical ratio. Its displayed quantiles describe underlying per-asset costs, not a fictitious distribution of group ratios.

Numeric features use Pearson correlation when neither variable has zero variance, plus persisted increasing numeric bucket thresholds. Default thresholds 0.2/0.4/0.6/0.8 are intended for normalized image measures, not universal units; customize them for entropy, aspect ratio or counts. Thresholds and a bucket-version label are retained per analysis. The service never silently rebuckets an old finding.

Both groups must meet the configured minimum (20 by default). Below it: INSUFFICIENT_DATA, LOW confidence. Sufficient groups whose interval includes zero: INCONCLUSIVE. An interval wholly on one side of zero is labeled descriptive SUFFICIENT_EVIDENCE, still exploratory. MEDIUM confidence additionally requires no detected major imbalance or capped sample. V1 deliberately does not award HIGH confidence to observational scans. All tested-comparison counts are retained. There are **no formal p-values/significance tests or winner declarations** in v1, so no false claim of corrected significance: every scan is explicitly exploratory, with unadjusted intervals. A future formal testing implementation must add a declared family and correction method.

Assumptions include independent asset-level observations, reasonably comparable exposure, correct metric mapping and stable measurement definitions. Shared concepts, repeated publication exposure, nonrandom platform delivery, incomplete observation, provider confounding, selection/survivorship bias and temporal drift violate simple interpretations. Stratification tables reveal some of these issues but do not solve them. Statistical evidence motivates a controlled experiment, not a global instruction to change prompts.
